# Git basic instructions

## CLONE FROM SCRATCH

```bash
git clone git@github.com:gavesako/PrateleDhammy.git
```

## PUSH AFTER EDITS

*Eseguire i comandi dalla cartella radice del progetto:*

```bash
git add .
```

```bash
git commit -m "commit message"
```

```bash
git push
```

## PULL LATEST UPDATES

```bash
git pull
```
